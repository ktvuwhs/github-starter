# github-starter

# Introduction
This assignment will help you learn the basics of using Github to modify and push code to repositories so that you can submit assignments.

## notes.txt
Answer the questions in the `notes.txt` file.

## intro.py
Look at the `intro.py` file.  Respond to the following prompts in the comments section of the program.
1. Before running the file, predict how you believe the program will behave when you run it.  Provide a sample input, and predict the output.
2. Run the program by typing `python intro.py` into the terminal.  What is the actual output?
3. Briefly describe why this happens?
4. How would you fix this issue?  Feel free to ask AI.  If using AI for assistance, then paraphrase / write in your own words what the fix would be.
5. Proceed to fix the program.  Re-run the program to check that it works.

## Submitting Code
In order for your code changes to take place, we need to "commit" and "push" the code to the repository.
* In the left hand side, click on the branch icon
* Add a commit message to describe changes to the files
* Commit the files
* Push (synchronize) the files
